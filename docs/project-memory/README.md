# Project memory export

Snapshot of the Cowork desktop project memory for **StartupAgents**, exported 2026-09-12 so the project context travels with the repo.

The desktop app stores project memory per machine. On a new machine, link this folder as a Cowork project and point Claude at `docs/project-memory/MEMORY.md` (or ask it to re-seed project memory from this directory). `MEMORY.md` is the index; each topic file has YAML frontmatter (`name`, `description`, `type`).

Keep this directory in sync: when project memory changes materially, re-export here and commit.
