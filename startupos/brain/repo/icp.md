# Ideal customer profile

## Segments
1. **OT/BAS-heavy enterprises** — building automation, controls, and operational-technology estates where agentic tooling is entering regulated environments (CRA readiness pressure).
2. **BAS/BMS vendors' product-security orgs** — companies shipping building-management and controller software (Niagara, Metasys, Desigo class) that need runtime assurance for AI-assisted development and agent deployments.

## Buyer personas
- **CISO** — owns agent runtime risk and audit evidence.
- **VP Engineering** — owns the fixer/eval path and developer platform adoption.
- **VP Product Security** — owns PSIRT, threat modeling, and CRA evidence packs.
