# Pricing

| Offer | Terms |
|---|---|
| CVE triage | Free for the first 50 assets |
| Per site | $2,000 / month per site after the free tier |
| CRA evidence pack | Packaged deliverable for CRA readiness (scan summary, findings by severity, proposed fixes, runtime evidence) |

## Conventions
- Quote in USD, monthly, per site. Annual only on request.
- The free triage is the wedge: run it on a public repo or a Niagara/Metasys build, then propose the per-site plan.
- POCs (e.g. JCI) run under NDA on internal repos; invoice drafts are triggered by POC milestones.
